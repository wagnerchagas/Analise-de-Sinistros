# Analise-de-Sinistros

# Projeto de Big Data — Análise de Sinistros

## Problema

Empresas de seguros possuem processos manuais e lentos para análise de sinistros, resultando em altos custos operacionais, demora no atendimento e dificuldade na identificação de fraudes.

---

## Dados

- Dados internos de segurados
- Redes sociais (Facebook e Instagram)
- Google Maps

### Descrição

Os dados incluem informações de clientes, localização, histórico de sinistros, valores e indicadores de fraude.

---

## Tecnologias

- Python
- SQL
- Power BI
- Pandas
- Scikit-Learn

---

## Metodologias

- CRISP-DM
- KDD
- Scrum
- DataOps

---

## Pipeline

Coleta → Limpeza → Transformação → Análise → Visualização

---

## Algoritmo Utilizado

Modelo de Classificação:

- Fraude
- Não Fraude

---

## Resultados

- Redução de fraudes
- Maior agilidade no processo
- Melhor tomada de decisão

---

## Insights

A análise mostrou padrões suspeitos em determinadas regiões e perfis de clientes.
